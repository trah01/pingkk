命令行用法

图形界面包已内置
操作命令
测试 TCP 端口pingkk example.com 443 tcp
测试 UDP 端口pingkk example.com 53 udp
同时测试 TCP 和 UDPpingkk example.com 53 all
测试多个端口pingkk example.com 80,443 tcp
持续测试pingkk -t example.com 443 tcp
Pingpingkk example.com
路由追踪pingkk example.com -r
一键网络检查pingkk --checkup
DNS 对比诊断pingkk --dns example.com
详细端口测试信息pingkk --advanced example.com 443 tcp
详细 DNS 诊断信息pingkk -a --dns example.com
自定义超时（毫秒）pingkk --timeout 1000 example.com 443 tcp

端口类型可选 tcp、udp 或 all。-t、-r / --route、-a / --advanced 和 --timeout / -w 可放在命令中的任意位置。

高级输出默认关闭，使用 -a 或 --advanced 可查看单包大小、丢包率、时延范围、波动及汇总统计。

支持的系统与下载包

前往 GitHub 下载 ↗

Windows

  • Windows 10 1809 及以上：x64
  • Windows 7 / Server 2008 R2 / Server 2016：x64 兼容版
  • Windows 10 1809 及以上 ARM 设备：ARM64

便携单文件 portable.exe，双击即可使用；另有 setup.exe 安装包和 cli.zip 命令行包。

macOS

  • Apple Silicon：ARM64，macOS 11 及以上
  • Intel：macOS 10.13 及以上

应用包 gui.zip，解压后打开 pingkk.app；另有 cli.zip 命令行包。首次打开请参考下方说明。

Linux

  • x86、x64、ARM64
  • 构建基线：Debian 10 / glibc 2.28
  • 图形界面需要 X11 或 XWayland

便携包 portable.tar.xz，解压后运行 run-pingkk.sh；另有 DEB 安装包和 cli.tar.gz 命令行包。

macOS 提示无法验证应用，怎么打开？

此版本未使用 Apple Developer ID 和公证。确认从本项目 Releases 下载后，在终端进入 pingkk.app 所在目录，执行以下命令，再双击打开应用。命令只清除此应用的下载隔离标记。

xattr -dr com.apple.quarantine pingkk.app
UDP 没有响应，是否意味着端口不通？

不一定。UDP 只有收到目标响应时才显示为连通；没有响应时显示“状态未知”，不能仅据此确定端口不通。
